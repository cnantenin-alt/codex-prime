Ce qu'il faut en retenir

Les deux listes ne se recoupent pas : elles ne couvrent pas la même étape d'un projet.

A Utile pour…

  • Donner un style à une page générée par IA : galeries d'inspiration, styles typographiques.
  • Trouver des composants prêts à l'emploi : shadcn/ui, Magic UI, Aceternity, 21st.dev (compatible MCP).
  • Animer : Motion Primitives, anime.js, effets de texte.
  • À prendre comme une piste de découverte : rien n'est vérifié ni daté, et le n°1 est une promotion.

B Utile pour…

  • Choisir son assistant de code : Claude Code, Cursor, Aider, Codex CLI…
  • Prototyper une app : Bolt.new, Lovable, v0, Replit.
  • Tester et sécuriser avant de publier : Playwright MCP, Semgrep, Prbl.
  • Déployer : par exemple Cloudflare via MCP, cohérent avec la publication de ce site.
  • Plus fiable, mais un instantané daté : revérifier prix et disponibilité avant usage.

🔗 Les combiner

  • B pour l'outil qui écrit et vérifie le code.
  • A pour le design qu'on lui demande de produire.
  • Exemple : demander à Claude Code (B) une page en shadcn/ui (A), la tester avec Playwright MCP (B), puis la publier.
