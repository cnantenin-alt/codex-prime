# Codex Prime

Mon premier dépôt GitHub, avec une page web prête pour **GitHub Pages**.

## 🌐 Site en ligne

Une fois GitHub Pages activé, le site est disponible ici :
**https://cnantenin-alt.github.io/codex-prime/**

## 📁 Contenu

| Fichier       | Rôle                                         |
|---------------|----------------------------------------------|
| `index.html`  | Page d'accueil du site (HTML + CSS intégrés) |
| `README.md`   | Ce fichier                                   |

## 🚀 Activer GitHub Pages

1. Ouvre **Settings → Pages** dans le dépôt.
2. Dans **Build and deployment**, choisis **Source : Deploy from a branch**.
3. Sélectionne la branche **`main`** et le dossier **`/ (root)`**, puis **Save**.
4. Après une minute environ, le site est publié à l'adresse ci-dessus.

> ℹ️ Avec un compte GitHub gratuit, GitHub Pages ne fonctionne que sur un dépôt **public**.

## ✏️ Modifier le site

Modifie `index.html` (directement sur GitHub avec l'icône ✏️, ou en local), puis enregistre (commit) : le site se met à jour automatiquement.
